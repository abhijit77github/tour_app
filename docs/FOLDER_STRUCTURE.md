## 📝 Adding New Documentation

When adding new documentation files:

1. **Determine the category:**
   - Project overview? → `/project`
   - Phase-specific? → `/phases`
   - Admin-related? → `/admin`
   - Technical guide? → `/guides`
   - Infrastructure? → `/deployment`

2. **Follow naming conventions:**
   - Use UPPER_CASE with underscores
   - Be descriptive (not just NOTES.md)
   - Include the category in the name when helpful

3. **Update relevant INDEX files:**
   - Update `/docs/README.md` if new major category
   - Update folder's quick reference
   - Cross-link from related documents

4. **Add to navigation:**
   - Update table of contents in main README
   - Add quick reference entry
   - Cross-link from existing documents
